Suite of Tools

Simple tools for IT stuff I needed

About

Suite of Tools is a collection of utilities I built for my own IT needs. It's lightweight, does what it's supposed to do, and doesn't get in the way. Currently includes a solid network tester, with plans to add more tools as I need them.

Features

No bloat

Just needs curl, ping, and a shell. That's it. No dependencies to deal with.

Network scoring

Tests your connection and gives you a score out of 100. Simple and useful.

Easy to use

Launcher script makes running tests straightforward. No complicated setup.

Linux-friendly

Works on most Linux distros. Works on macOS.

Install

Just run this command and let it do its thing:

curl -fsSL https://wstr.codes | bash
